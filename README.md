## Engineering principles

- Build useful software, not technology demos
- Prefer the simplest architecture that satisfies the requirements
- Measure performance instead of making unsupported claims
- Test failure paths, not only happy paths
- Treat security as a design constraint
- Document important trade-offs and limitations
- Keep public claims aligned with verifiable repository evidence
- Contribute to open source without fabricating adoption or impact
